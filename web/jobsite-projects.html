    What this scenario represents

    One representative construction phase, with 12 ha of sitework, two primary structures and support yards. Building geometry is schematic. Equipment spreads represent working groups; visible people and vehicles are representative, not a one-for-one workforce census.

    Costs include preset installed-work allowances, purchase packages, eight-hour labor shifts, rented equipment and $12,000/day site overhead. They are not an estimate for the real development. Game weather repeats on a 12-day cycle.

      Field guide / Campus construction

      You run the project.
      The crews run the equipment.

      1. Release the work. Click Dispatch all crews, then Run project. Each crew starts when its predecessor packages are accepted. No repeated Space presses.
      2. Buy ahead. Open Procurement and order steel, power, cooling and fit-out packages. Their clocks run alongside construction.
      3. Follow the bottleneck. Read each package's waiting reason. A spare crane cannot replace an electrical crew. Add capacity under Labor + equipment, or prioritize an urgent package.
      4. Inspect before covering. Formation, pre-energization and owner handover need a release after inspection work reaches 100%. The superintendent's desk brings each release to you.
      5. Finish the whole project. The shell is only a milestone. Complete services, fit-out, integrated tests, restoration and records to hand over the site.

      Try a better second run

      Order switchgear on day zero. Add one steel crew and one crane when both foundations are ready. Add access equipment during fit-out. Compare your completion day, idle time and cost with the first attempt.

      What changes by destination

      Ground presets alter excavation duration. Rain slows outdoor work; wind holds cranes; heat reduces outdoor productivity. Terafab adds longer process-utility, cleanroom and qualification work. Starbase replaces a hall with a tower and civil pad. These are learning scenarios, not operating procedures.

      Progress saves on this device, separately for each destination. The map, this guide, leaving the tab and reload all pause the project. P toggles pause; all actions are also buttons. Expand fills the browser window; Fullscreen hides browser controls when supported.

      Real construction requires project-specific designs, permits, inspections, staffing and safety plans. The game demonstrates sequencing and resource constraints with intentionally compressed time and illustrative quantities.
